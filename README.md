📖 Инструкция по использованию приложения

📱 1. Назначение приложения

Приложение предназначено для:
отображения карты местности;
определения текущего местоположения пользователя;
добавления пользовательских меток (событий) на карту.
🚀 2. Запуск приложения
Установить приложение на устройство или запустить через Android Studio
Открыть приложение
При первом запуске:
разрешить доступ к геолокации 📍
🗺️ 3. Работа с картой

После запуска:

на экране отображается карта (OSM) можно:
перемещать карту пальцем
увеличивать и уменьшать масштаб (щипок)
📍 4. Определение местоположения
приложение автоматически показывает текущее положение пользователя
оно отображается в виде точки на карте
карта может автоматически центрироваться на пользователе

📌 Если точка не отображается:

включите GPS
проверьте разрешения
📌 5. Добавление события на карту

Чтобы добавить точку:

Нажмите на любое место на карте
Появится меню выбора события
Выберите один из вариантов:
ДТП
Ремонт дороги
Другое
✏️ 6. Добавление собственного события

Если выбрать "Другое":

Откроется окно ввода
Введите текст (например: "Пробка")
Нажмите OK

После этого:

на карте появится маркер 📌
при нажатии на него будет отображаться текст
🔍 7. Просмотр информации о точке
нажмите на маркер
появится название события
⚠️ 8. Возможные проблемы

Не отображается карта:

проверьте интернет-соединение

Нет текущего местоположения:

включите GPS
выдайте разрешение приложению

Не добавляются точки:

убедитесь, что нажимаете именно на карту
🧠 9. Особенности работы
точки не сохраняются после закрытия приложения
все события отображаются только в текущей сессии
карта загружается через интернет
📌 10. Завершение работы

Для выхода:

нажмите кнопку "Назад"
или
закройте приложение стандартным способом
